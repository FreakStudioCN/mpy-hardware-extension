# 从一个想法到量产：硬件全链路零基础教学手册

> 写给**完全没有电子/硬件/制造基础**的人。每个术语第一次出现都用大白话解释 + 给英文原词。
> 贯穿示例：做一个「ESP32 温湿度显示小设备」，从脑子里的想法一直走到量产 100 台。
> 供应链**中美双覆盖、并列对比**（以中国为主）。
>
> 日期：2026-06-22 ｜ 来源：deep-research（5 路搜索 + 126 条对抗式核验事实，文末附来源）。

## 怎么读这份文档

硬件和软件最大的不同：**软件改一行重新跑就行，硬件每错一步都要花钱、花周（不是花秒）重来。** 所以整个行业把流程切成一段段「关卡」，每过一关才准烧下一笔钱。这份手册就是带你逐关走一遍。

先记住一句话——**硬件创业 97% 会失败**（来源 predictabledesigns），主要死因不是技术，是「做了个没人要的东西」。所以**第 1 章「想法/需求」比后面任何技术环节都重要**：先用最便宜的方式验证有人要，再往下烧钱。

## 第 0 章：先看全局地图（最重要，先建立框架）

整条链路一句话：**想法 → 选型 → 画电路（原理图）→ 画板子（PCB）→ 打样 → 买料 → 贴片组装 → 测试 → 做外壳 → 拿认证 → 量产 → 包装发货。**

### 0.1 行业把这条线叫什么——两套「阶段」黑话

你在英文资料里会反复撞见两套缩写，它们说的是同一条线的不同切法，**必须先认识**：

**切法 A：按「验证关卡」切（最常用）**

```
POC  →  EVT  →  DVT  →  PVT  →  MP（量产）
```

| 缩写 | 全称 | 大白话 | 典型数量 | 典型周期 |
|---|---|---|---|---|
| **POC** | Proof of Concept（概念验证） | 用开发板搭个「能证明这事儿能成」的丑原型 | 1～几个 | 几天～几周 |
| **EVT** | Engineering Validation Test（工程验证） | 第一次把「长得像」+「功能像」合到一块定制板上，挑出能量产的设计 | 3～50（常 5~12），有的资料说 20~50 | 最少 4–5 周 |
| **DVT** | Design Validation Test（设计验证） | 用「接近量产的工艺/真模具」做，验证良率、过认证、定包装 | 20～200（也有说 300~2000） | **最少 8 周（最难的一关）** |
| **PVT** | Production Validation Test（生产验证） | 用真正的量产线、量产速度跑一小批，验证「线能不能稳定出货」，这批货可以拿去卖 | 50～500（约首批量产的 5–10%） | 最少 4 周 |
| **MP** | Mass Production（量产） | 多条产线并行开足马力 | 1000～20000+ | 持续 |

> 小白记忆法：**POC=能不能成 ｜ EVT=功能对不对 ｜ DVT=能不能造、合不合规 ｜ PVT=线稳不稳 ｜ MP=开足马力。** 每一关都比上一关贵一个数量级，且 EVT 阶段**坏 40% 是正常的**（来源 instrumental / kdproductdev）——别被吓到，那就是它存在的意义。

**切法 B：按「大阶段」切（偏设计公司口径）**

`想法(Ideation) → 原型(Prototyping) → 产品化(Productization)`（来源 MistyWest），或更细的 6 段：概念→产品设计→工程与制造验证→质量与法规→量产上市→上市后迭代（来源 StudioRed）。两套是同一条线，记住切法 A 即可。

### 0.2 一张「钱与时间」的体感表

| 你在哪一步 | 一次迭代花多少钱（量级） | 改一次要多久 |
|---|---|---|
| 写固件（软件） | ~0 | 秒～分钟 |
| PCB 打样（中国） | 几块～几十块人民币 | ~7 天 |
| PCB 打样（美国直厂） | $350～$1000+ | 几天～两周 |
| 开注塑模具 | $2,000～$100,000+ | 8–12 周 |
| 拿一张无线认证 | $3,000～$40,000+ | 8–12 周 |

**这张表解释了一切设计取舍**：能在软件里改的别动硬件，能在打样阶段改的别等开模，能用现成认证模块的别自己设计射频。

## 第 1 章：想法 / 需求定义（最便宜、最该认真的一步）

**这一步在干嘛**：把「我想做个 XX」翻译成一份能落地的需求，并判断值不值得做。
**产出物**：一句话产品定义 + 需求清单 + 目标成本 + 粗 BOM 预算。
**周期/成本**：几天，几乎不花钱——但决定后面所有钱的去向。

### 必须想清楚的几件事
- **一句话定义**：谁、在什么场景、用它解决什么。例：「给养花的人，一个放桌上、能显示温湿度、超阈值提醒的小盒子」。
- **需求拆解**：功能需求（显示温湿度）、传感（温湿度传感器）、交互（屏幕/按钮）、通信（要不要 WiFi 上报）、供电（USB 还是电池）、外形/成本目标。
- **目标成本（target cost）**：先定「这东西卖多少钱、BOM 成本控制在多少」。**BOM = Bill of Materials（物料清单）**，就是「这台机器里所有零件的购物车清单 + 单价」。一般 BOM 成本要 ≤ 售价的 1/3～1/4。
- **可行性 + NRE**：**NRE = Non-Recurring Engineering（一次性工程费）**，指「只花一次」的研发投入——工业设计、结构、电路、固件、软件、DFM 等（来源 predictabledesigns）。做一个能用的原型，工程投入大约是早期阶段的 **10～100 倍**，要有心理准备。

### 新手易错点
- 一上来就画电路、选芯片——**顺序错了**。先验证「有人要」（给目标用户看草图/假落地页/众筹意向）。
- 把「我自己觉得酷」当成「市场需要」。97% 死在这。

## 第 2 章：方案与选型（选大脑、选感官、选供电）

**这一步在干嘛**：决定用什么**主控芯片（MCU）**、什么**传感器/模块**、怎么**供电**、要不要**无线**。
**产出物**：方案框图（block diagram）+ 关键器件选型表。
**常用工具**：纸笔 / 框图工具；器件查询用立创商城、Digi-Key、Mouser。

### 2.1 主控 MCU 怎么选
**MCU = Microcontroller Unit（微控制器）**，就是设备的「大脑」——一颗能跑你程序、控制各个零件的小芯片。

新手在 IoT/小电子领域**首选 ESP32**（乐鑫 Espressif 出品），原因很实在：
- **WiFi + 蓝牙都集成在芯片里**（来源 espressif / predictabledesigns）。这一点极其省事——否则你要单独搞天线、射频电路、配套 MCU，每一样都是坑。
- 性能够用：单/双核、主频 240MHz、448KB ROM、520KB SRAM（来源 espressif）。
- 生态好、资料多、便宜。固件可以用 **Arduino IDE**（简单、可移植）或乐鑫官方的 **ESP-IDF**（更底层、带 FreeRTOS 实时系统，控制力更强）（来源 predictabledesigns）。
- 关键策略：**从 POC 到量产尽量用同一颗主控**（比如全程 ESP32），这样固件几乎不用重写，跨阶段迁移最省力（来源 predictabledesigns）。

其他常见主控：**STM32**（工业/对实时和功耗要求高时常用）、**Raspberry Pi / 树莓派**（要跑 Linux、要算力/摄像头时；但它是「电脑」不是「单片机」，功耗大）。

### 2.2 传感器/模块、供电、无线
- **传感器**按需选：温湿度（如 AHT20、SHT30）、光照（BH1750）、气压、运动（IMU）等。
- **模块（module）**：把一颗芯片 + 外围电路做成的「即插即用小板」，新手阶段优先用模块（省去自己设计芯片外围）。
- **供电**：USB 直供最简单；要做电池就要加**锂电池 + 充电管理 + 稳压**，复杂度和认证都上一个台阶。
- **无线**：用 ESP32 这类**预认证模块**，能帮你躲掉后面最贵的射频认证（见第 10 章）。

### 新手易错点
- 为「以后可能用得上」堆一堆功能 → BOM 暴涨、板子变大、认证变贵。**先做最小可用。**
- 选了冷门芯片，结果没库存/没驱动/没资料。**优先选生态成熟、立创有现货的型号。**

## 第 3 章：原理图设计（画「电路逻辑图」）

**这一步在干嘛**：把「哪个零件和哪个零件怎么连」画成一张逻辑图。
**产出物**：原理图（schematic）+ 网表（netlist）。
**常用软件**：**KiCad**（免费开源，专业/业余都用，支持最多 32 层铜，全平台）、**嘉立创EDA / JLCEDA**（浏览器免安装、中文友好、和打样/买料打通）、**Altium**（专业付费，公司多用）。

### 3.1 几个必须懂的基本概念
- **原理图（schematic）**：用符号画「逻辑连接」，不管零件实际在哪、多大。像地铁线路图——只关心站点怎么连，不关心真实地理。
- **网表（netlist）**：原理图导出的一张「谁连谁」的清单，是原理图传给 PCB 的桥梁。
- **封装（footprint）**：一个零件在板子上对应的**一组铜焊盘**，形状和零件的引脚一一对应；造板时零件就焊在它的封装上（来源 sparkfun）。⚠️ **同一个符号可以对应不同封装**（比如电阻有大有小）——在 KiCad 里你必须**手动给每个元件指定封装**（用 CvPcb 工具），它不会自动帮你连（来源 sparkfun）。这是新手头号坑。
- **datasheet（数据手册）**：芯片厂给的「说明书」，里面有引脚定义、电气参数、典型电路、寄存器表。**学会读 datasheet 是硬件入门的核心技能。** 在 Digi-Key/Mouser 每个商品页都直接链到 datasheet（来源 predictabledesigns）。

### 3.2 基础元件大白话扫盲
| 元件 | 英文 | 一句话作用 |
|---|---|---|
| 电阻 | Resistor | 限制电流大小（像水管阀门拧小） |
| 电容 | Capacitor | 存/放电、滤波稳压（像小水库削峰填谷） |
| 二极管 | Diode | 让电流只能单向流（单向阀） |
| 三极管 | Transistor (BJT) | 用小电流控制大电流（电子开关/放大器） |
| MOS管 | MOSFET | 用电压控制大电流的开关（驱动电机/电源开关常用） |
| 稳压器 | Voltage Regulator | 把不稳的电压变成稳定的（如 5V→3.3V） |
| 晶振 | Crystal/Oscillator | 给芯片提供精准「心跳节拍」（时钟） |

### 3.3 标准流程（以 KiCad 为例）
KiCad 是个套件，各干一摊（来源 KiCad docs / sparkfun）：
1. **Eeschema** 画原理图 →
2. 做 **ERC（Electrical Rules Check，电气规则检查）**，查有没有漏接/短接 →
3. 生成**网表** →
4. **CvPcb** 给每个元件指定封装 →
5. 进第 4 章的 PCB 布局。

> 中国路径同理：嘉立创EDA 的完整链路是「创建器件符号 → 创建封装 → 建工程 → 画原理图 → 转 PCB → 布局布线 → 生成生产文件」（来源 lceda 文档）。

## 第 4 章：PCB 设计（把逻辑图变成「真板子」）

**PCB = Printed Circuit Board（印刷电路板）**，就是那块绿色（或其他颜色）的板子，上面的铜线把零件连起来。
**这一步在干嘛**：把原理图的逻辑连接，变成零件在板上的真实位置 + 真实铜线走法。
**产出物**：PCB 设计文件 → 导出**生产文件**（Gerber + 钻孔文件 + 坐标文件 + BOM）。
**常用软件**：KiCad 的 **Pcbnew**；嘉立创EDA；Altium。

### 4.1 必懂概念
- **布局（layout）**：决定每个零件摆在板上哪里。
- **布线（routing）**：画铜线（**走线/track**）把零件按网表连起来——你画的走线就是成品板上真实的铜（来源 sparkfun）。
- **层（layer）/ 叠层（stackup）**：板子可以是单层、双层、多层（KiCad 支持到 32 层）。一块典型双层板的标准层有：顶/底铜（F.Cu / B.Cu）、顶/底阻焊（F.Mask / B.Mask，就是绿油层）、顶/底丝印（F.SilkS / B.SilkS，板上的白字）、板框（Edge.Cuts，外形轮廓）（来源 sparkfun）。
- **过孔（via）**：穿过板子把不同层的铜连起来的小孔。
- **铺铜（copper pour）**：把空白区域铺成大块铜（通常接地），改善散热和抗干扰。
- **阻抗（impedance）**：高速/射频信号的走线要控制「阻抗」，否则信号会失真（小白阶段：用 ESP32 模块就不用自己操心天线阻抗）。
- **DFM = Design for Manufacturing（可制造性设计）**：让你的设计「工厂造得出来、造得便宜」——线别太细、孔别太小、间距别太挤。SparkFun 的可靠基线是：走线宽 10mil、间距 10mil、过孔 20mil（来源 sparkfun；1 mil = 0.0254mm）。
- **DRC = Design Rules Check（设计规则检查）**：自动检查你的板子有没有违反工厂工艺（线太近、孔太小等）。**过了 DRC 才能出生产文件**（来源 KiCad docs）。

### 4.2 生产文件——工厂到底要什么（必记）
一套完整 PCB 生产文件有三类交付物（来源 advancedpcb / jlcpcb）：

1. **PCB 制板数据**：
   - **Gerber 文件**——行业最通用格式，每一层一个 Gerber 文件，所有软件能导出、所有厂能读（来源 KiCad / advancedpcb）。是「板子长什么样」的标准语言。
   - **钻孔文件（drill / NC file）**——定义每个孔的位置，常见 Excellon 格式，含坐标+刀具号+钻头直径表（来源 advancedpcb）。
2. **装配文档**：装配图 + **坐标文件（pick-and-place / 贴片坐标 / Centroid）**——告诉贴片机每个零件放哪、朝向、在正面还是反面；没有它自动贴片机没法工作（来源 advancedpcb）。
3. **BOM（物料清单）**：通常 Excel，列出所有零件型号/数量/位号，是采购和贴片的唯一依据（来源 advancedpcb）。

> 一句话：**Gerber=板长啥样，钻孔=孔在哪，坐标=零件放哪，BOM=用哪些零件。** 这四样给工厂，就能造。

### 新手易错点
- 没指定封装/封装选错 → 零件焊不上去。
- 没过 DRC 就下单 → 工厂打回或直接做坏。
- 丝印（白字）压到焊盘、板框没画闭合 → 常见退单原因。

## 第 5 章：打样（先做几片出来验证）

**打样 = 小批量先做几片**，验证设计对不对，再决定要不要量产。
**产出物**：几片真实 PCB（裸板）/ 已贴好件的样板。
**周期/成本**：中国裸板最快当天～7 天、几块到几十块钱；美国直厂几百刀。

### 5.1 中国路径（最便宜最快，强烈推荐打样用）

**嘉立创 JLCPCB / 立创EDA 一条龙**（深圳嘉立创科技集团，来源 jlc.com 官方）：
- **下单价**：FR-4 标准板 **¥20 / 5 片起**；部分板型**免费打样**（来源 jlc.com）。
- **速度**：作者实测「每次都在 7 天内收到板」（来源 predictabledesigns）。
- **免费券福利**：用嘉立创EDA 设计，**每月可免费领 2 张打样券**（1~4 层喷锡券、2~4 层沉金券，6 层沉金券需先通过嘉立创知识考试）（来源 lceda wiki）。
- **一键下单**：在嘉立创EDA 里点「在嘉立创下单」，系统**自动生成 Gerber + 坐标 + BOM** 并下单，用 EDA 账号登录、无需单独注册（来源 lceda 文档）。也可本地导出 Gerber 再去 jlc.com「PCB订单管理→在线下单」手动上传。
- **下单填参数要点**（新手照抄）（来源 lceda 文档）：
  - **板厚填 0.8mm~1.6mm**（非标厚度要加钱）。
  - **选绿色阻焊油墨**——**绿油 48 小时免费加急**，交期最快、成本最优；其他颜色更慢更贵。
- **质量特点**：交期快、便宜；但丝印细节会糊、阻焊偏薄（来源 PCB 横评）。打样足够，高端外观件另说。
- **承诺**：加急交期 99.9%+ 准时、普通 95%+，「坏一赔十」（来源 jlc.com）。

**其他中国厂**：
- **PCBWay**：约 **$3–4/片**；横评里**唯一会主动联系你确认设计问题**（有人工审单）、唯一发现了一个坏孔——审核更细，但阻焊对位略差（来源 PCB 横评）。
- **Seeed Studio Fusion**：深圳，打样 + 小批量 + 含部分认证/代工，海外开发者常用。

### 5.2 美国/国际路径

| 厂 | 定位 | 价格 | 特点 |
|---|---|---|---|
| **OSH Park** | 美国众包打样 | $5/3in²，超出 $1/in²，3 片起，**免运费、100% 美产、不踩关税** | 板子「漂亮」、质量最高，但贵；可直接拖 KiCad 文件下单（来源 PCB 横评 / sparkfun） |
| **PCB 直厂（如 Advanced Circuits / Sierra）** | 美国本土快板 | **~$350/几片**，加急 **$1000+** | 快、合规、贵几个数量级 |

### 5.3 贴片打样 & 3D 打样
- **SMT 打样（贴片）**：嘉立创SMT（JLCSMT）**焊点费低至 ¥0.005/焊点、工程费仅 ¥50、钢网免费、2 片起、最快 15~24 小时发货**，90% 基础库订单半天完成贴装（来源 jlc-smt 官方）。意思是：你不用自己焊，几十块就能让工厂帮你把样板贴好。
- **3D 打样**：嘉立创也有 3D 打印 / CNC，做外壳样件。

### 中美怎么选（打样）
- **打样几乎都选中国**：便宜 5–10 倍、快。一片小板中国 ~¥1.5–4，OSH Park ~$15、美国直厂 ~$350（来源 predictabledesigns / 横评）。
- 例外：**只做极小面积板、又怕关税/要本土合规** → OSH Park 免运费免关税反而划算；**大面积板**即使交关税，JLCPCB/PCBWay 仍更便宜（来源 横评）。

## 第 6 章：元件采购（去哪买零件）

**这一步在干嘛**：按 BOM 把所有零件买齐。
**核心风险**：买到**假货/翻新料**、买错封装、买到没库存的料。

### 6.1 中国路径
- **立创商城 LCSC（szlcsc.com）**：一站式元件采购，**76 万+ 现货 SKU**，电容/电阻/电感/MCU/二极管/三极管/连接器/传感器全覆盖；智能仓储**最快 4 小时发货**；含 Nexperia、Panasonic、Nordic、扬兴 YXC 等 20+ 品牌（来源 szlcsc 官方）。**和嘉立创EDA + JLCPCB + JLCSMT 同属一个生态，设计→买料→打样→贴片在一个体系内闭环**（来源 lceda / jlcgroup）。
- **华强北（深圳）**：全球最大电子市场，便宜、品类全、能淘冷门料；但**真假混杂、要会辨货**，适合有经验的人或现场看货。

### 6.2 美国/国际路径
- **Digi-Key / Mouser**：**授权分销商**——直接从原厂按正式分销协议进货，**几乎没有假货风险**；每个商品页直链 datasheet/参考设计/应用笔记；有 BOM 管理工具，能按 1～10000 不同数量给阶梯价（来源 predictabledesigns）。
- **Arrow**：另一家大型授权分销。
- ⚠️ **Amazon 一般不是授权分销**，有中等假货风险、没有参数化搜索、datasheet 链接不全（来源 predictabledesigns）。例：官方 ESP32-DevKitC 在 Mouser/Digi-Key ~$10；Amazon ~$8 常是「能用的克隆板」，USB 转串口芯片可能从 CP2102 换成 CH340（来源 predictabledesigns）。

### 6.3 采购铁律（来源 predictabledesigns）
> **学习/玩票**：哪便宜买哪（华强北、淘宝、Amazon 都行）。
> **要变成产品 / 有融资的正经项目**：「**Mouser 或 Digi-Key，没得商量**」——可追溯、无假货，省下的麻烦远超差价。

**国产替代**：很多进口料有国产 pin-to-pin 替代（更便宜、立创有货），但要核对 datasheet 参数是否真的一致。

## 第 7 章：PCBA 贴片与组装（把零件焊到板上）

**PCBA = PCB Assembly（已贴装电路板）**——裸板 + 零件焊好 = 一块能用的板。
**两种焊法**：
- **SMT = Surface Mount Technology（表面贴装）**：贴片机把小元件贴到板面，过回流焊炉一次焊好。主流、适合量产。
- **DIP / 插件（Through-Hole）**：带引脚的大元件插孔里焊，靠手工或波峰焊。

### 7.1 SMT 流程（大白话）
1. **钢网（stencil）+ 锡膏（solder paste）**：钢网是一张镂空钢片，把**锡膏**（焊锡微粒+助焊剂的膏）刮印到焊盘上。
2. **贴片（pick-and-place）**：贴片机按你的**坐标文件**把每个零件啪啪贴上去。
3. **回流焊（reflow）**：整板过一个温度曲线受控的炉子，锡膏熔化、把零件焊牢——「过炉」。
4. **AOI = Automated Optical Inspection（自动光学检测）**：摄像头自动查漏贴/错贴/连锡。
5. **X-ray**：查 BGA/QFN 这类「焊点藏在零件底下、肉眼看不见」的器件（来源 advancedpcb）。
6. **DIP/插件 + 检验**：插件元件后焊、终检。

### 7.2 贴片需要给工厂哪三样（必记）
**只要三份文件**：**BOM + 坐标文件（pick-and-place）+ 装配图（assembly drawing）**（来源 advancedpcb）。BOM 是采购和贴片的唯一真相源。

### 7.3 中国 PCBA（嘉立创SMT 为例）
- **价格**：**¥0.005/焊点、工程费 ¥50、钢网免费、2 片起、最快 15 小时发货**（来源 jlc-smt）。
- **产能**：**100+ 条全自动产线、最高 4.5 万点/小时**贴装；支持 BGA、连接器、客供料、双面贴（来源 jlc-smt）。
- 意义：小批量贴片在中国是「白菜价 + 极快」，这是中国供应链对创客最大的友好点。

### 中美对比
- **PCBA 设置费/NRE**：美国 **$300–800** vs 中国 **$50–150**（来源 研究）。
- **超过 100 台**通常中国更划算；**纯打样/几台**美国本土厂更快省心（来源 研究）。

## 第 8 章：测试与调试（保证每台都能用）

**这一步在干嘛**：烧固件 + 验证每台板子功能正常，量产时还要保证良率。
**关键术语**：
- **烧录固件（flashing）**：把你的程序写进 MCU。ESP32 用 USB 直接烧。
- **FAI = First Article Inspection（首件检验）**：量产开线前，先做一台，逐项核对编程、对位、实测值是否符合设计，过了才准批量（来源 研究）。
- **FCT = Functional Circuit Test（功能测试）**：通电跑一遍真实功能（屏幕亮不亮、传感器读数对不对）。
- **ICT = In-Circuit Test（在线测试）**：用探针床逐点量元件，查虚焊/错料/短路。
- **夹具 / 治具（fixture / jig）**：为快速测试做的专用「卡座」，板子一放就能自动通电测、烧录。
- **良率（yield）**：合格率。EVT 阶段坏 ~40% 正常（来源 instrumental）；越往后良率要越高。
- **AOI / X-ray**：见第 7 章。
- **工艺等级**：高可靠产品通常按 **IPC-A-610 Class 3** 验收（医疗/航天级）（来源 研究）。
- **可追溯性（traceability）**两档（来源 研究）：
  - **批次级（lot-level）**：能追到「哪一批」，出问题要隔离整批。
  - **单件级（unit-level）**：每块板有唯一条码/激光码，能追到「这一台」用的料、工艺、检测——医疗/航天常要求这级。

---

## 第 9 章：外壳 / 结构件（让它像个产品）

**这一步在干嘛**：给电路板做个壳，从「裸板」变「产品」。
**产出物**：外壳 3D 模型 + 实体外壳。
**常用工艺三选一**：

| 工艺 | 英文 | 单件成本 | 开模费 | 周期 | 适合 |
|---|---|---|---|---|---|
| 3D 打印 | 3D printing | **$5–50/件** | 几乎为 0 | 几天 | 打样、几十件以内 |
| 数控加工 | CNC machining | 中等 | 低 | 中 | 小批量、金属件、高精度 |
| 注塑 | Injection Molding | **$0.5–5/件** | **铝模 $2k–10k；钢模 $10k–100k+** | **钢模 8–12 周** | 量产（量越大越省） |

**关键决策——什么时候该开模**：3D 打印 vs 注塑的盈亏平衡点大约在 **100～500 件**（简单件 150–250，复杂件 600–800）（来源 研究）。
例：做 500 个小支架，3D 打印总价 ~$7,500，注塑 ~$6,000（$5,000 模具 + $2/件）——**过了平衡点注塑就赢**（来源 研究）。
**快速/铝模**：$2,000–$15,000，2–4 周交期，适合过渡（来源 研究）。

**工业设计（ID = Industrial Design）**：决定外观/手感/人机；结构工程把 ID 变成「装得下板子、扣得住、造得出」的真壳。

### 新手易错点
- 没量就开钢模 → 几万块打水漂。**先 3D 打印验证装配，过了销量平衡点再开模。**
- 外壳没给板子留装配公差/螺丝柱/散热 → 装不进去。

## 第 10 章：认证合规（不拿证不让卖）

**这一步在干嘛**：证明你的产品**不乱发射电磁、不干扰别人、对人安全、不含禁用物质**，否则**违法、不能上架、海关扣货**。
**周期/成本**：从几千到几万美元、8–12 周（加速可 1–2 周）。

### 10.1 美国 FCC（无线/电子产品必碰）
**FCC = Federal Communications Commission**。在美国卖电子产品必须验证「发射的射频在限值内」（来源 compliancetesting）。两条路（来源 acbcert / f2labs）：
- **非故意辐射体（unintentional radiator，Subpart B）**：本身不打算发无线的电子设备。走更轻的 **SDoC = Supplier's Declaration of Conformity（供应商符合性声明）**，**约 $3,000–$5,000**。
- **故意辐射体（intentional radiator，Subpart C）**：WiFi/蓝牙等主动发射的。要走完整 FCC Certification，**可达 $40,000+**（来源 f2labs）——比 Subpart B 贵一个数量级。

**省钱关键（创客必看）**：用**已带「模块化认证（modular approval）」的预认证模块**（如 ESP32 模组），你就**不用自己做最贵的 Subpart C**，只做较便宜的 Subpart B / SDoC（来源 acbcert / compliancetesting）。
⚠️ **但「用了认证模块 ≠ 整机免测」**：因为集成进设备会改变整机的电磁兼容（EMC），**最终成品仍需自己送 FCC 实验室做 Part 15 测试**才能上市（常可走较轻的 SDoC 流程）（来源 compliancetesting）。
**周期**：FCC 申请约 8–12 周；通过 **TCB（Telecommunication Certification Body，电信认证机构）**加速可缩到 1–2 周（来源 研究）。

### 10.2 其他常见证
| 证 | 区域/含义 |
|---|---|
| **CE** | 欧盟市场准入（安全/EMC 等综合） |
| **RoHS** | 限制铅/汞等有害物质（欧盟，电子必备） |
| **REACH** | 欧盟化学物质法规 |
| **UL** | 美国安全认证（尤其接市电/电源类） |
| **SRRC** | 中国无线电型号核准（在中国卖无线产品要） |
| **3C（CCC）** | 中国强制产品认证 |

欧洲一般至少要 **RoHS + CE**，接直流电源时可能要 UL（来源 研究）。**认证通常在 DVT 阶段做**（那时才有接近量产的真件）（来源 研究）。

### 新手易错点
- 自己设计射频天线 → 直接踩 $40k+ 的 Subpart C。**用预认证模块躲掉。**
- 以为「模块有证整机就免测」→ 海关/平台抽查翻车。

## 第 11 章：量产（开足马力造）

**这一步在干嘛**：稳定地、大批量地、合格地造出来。
**找谁造**：**EMS = Electronics Manufacturing Services（电子代工厂）**——你给设计和料，它帮你产线化生产。中国 EMS 极成熟；美国有 MacroFab 这类。

### 量产前的三道关（回到第 0 章的 EVT/DVT/PVT）
- **EVT**：功能定型，挑出能量产的设计（坏 40% 正常）。
- **DVT**：用接近量产工艺验证良率 + 过认证 + 定包装（最难、最少 8 周）。
- **PVT**：用真量产线跑一小批（首批的 5–10%），验证「线稳不稳」，这批能拿去卖。
- **MP**：多线并行、持续爬坡良率。

### 品控（QC = Quality Control）三个常见关卡
- **IQC = Incoming Quality Control（来料检验）**：进厂的料先查，靠 **CoC（Certificate of Conformance，符合性证书）**追到原厂、比对 RoHS/REACH/UL，降低翻新/假料风险（来源 研究）。
- **过程检验**：FAI 首件 + AOI/X-ray + FCT/ICT（见第 7、8 章）。
- **OQC = Outgoing Quality Control（出货检验）**：发货前抽检。

完整 PCBA 质量文档包含四类：工程文件（Gerber/BOM/坐标）、装配与工艺标准（装配图/IPC 等级/回流曲线）、可追溯与物料管控（CoC/批号/日期码）、质检与测试记录（FAI/AOI/X-ray/FCT/ICT/返修记录）（来源 研究）。

### 小批量 vs 大批量
- **10–1000 台（小批量）**：中国 PCBA 白菜价、嘉立创这类就能接；适合首发、众筹。
- **大批量**：找专门 EMS、谈阶梯价、上多产线。

## 第 12 章：包装与物流（送到用户手上）

**这一步在干嘛**：包装设计 + 说明书 + 出货 + 跨境运输 + 关税。
**要点**：
- **包装/说明书**：保护运输 + 合规标识（认证 logo、警示语）+ 用户引导。
- **物流时效**（来源 研究）：美国本土组装 **5–10 天**到门；中国**空运 12–18 天**、**海运最长 40 天**。
- **跨境关税（中→美，2025–2026 快照，波动极大，务必复核）**：
  - **Section 301 关税**：整机 PCBA 进口加 **25%–35%**；扣掉后中国对美仍有 **15%–25% 净成本优势**（来源 研究）。
  - 截至 **2025-05-15 有过 55% 的 PCB 进口关税**说法，且 **$800 以下小包免税（de minimis）已被取消**——小批量再也不能靠「拆小包免税」（来源 研究）。
  - **HTS 编码**：裸板 **8534.00**（基础税常为 Free，但叠加 301 的 25%）、某些 PCBA **8473.30**；部分 2/4 层硬板可用 301 排除码 **9903.88.69**（有效期到 2026-11-09）（来源 研究）。
  - **落地成本公式**：FOB 货值 + 运费 + 25% 关税 + 报关/清关费。例：$25,000 FOB + $1,500 运费 + $6,250 关税 + $400 杂费 = **$33,150 落地**（来源 研究）。关税按发票全额线性叠加：$100 板落地 ~$174、$1,000 板 ~$1,570、$10,000 板 ~$15,645（含关税+处理+DHL）（来源 研究）。

## 贯穿示例：ESP32 温湿度显示小设备，从想法到量产 100 台

**产品**：桌面小盒，ESP32 + AHT20 温湿度传感器 + 小 OLED 屏，USB 供电，超阈值闪屏提醒。

| 步骤 | 走中国供应链 | 走美国供应链 |
|---|---|---|
| **1 想法/需求** | 一句话定义 + 目标 BOM ≤ ¥60/台；先给 10 个养花朋友看草图验证 | 同 |
| **2 选型** | ESP32-WROOM 模块 + AHT20 + 0.96" OLED；USB 供电 | 同 |
| **3 原理图** | 嘉立创EDA（免费、中文、直连买料打样） | KiCad（免费） |
| **4 PCB** | 嘉立创EDA 画双层板，过 DRC，导 Gerber/坐标/BOM | KiCad 出 Gerber |
| **5 打样(5 片)** | JLCPCB 双层板，**绿油+1.6mm**，~¥20 或**免费券**；7 天到 | OSH Park ~$15+，或美国直厂 ~$350 |
| **6 买料** | 立创商城（ESP32 模块~¥18、AHT20~¥3、OLED~¥12、被动件~¥3）；最快 4h 发货 | Digi-Key/Mouser，单价更高、正品无忧 |
| **7 贴片样板** | JLCSMT，**¥50 工程费 + ¥0.005/焊点 + 钢网免费**，2 片起，~15–24h | 美国 PCBA NRE $300–800 |
| **8 测试** | 烧固件、FCT 验证温湿度/屏显；做个简单测试治具 | 同 |
| **9 外壳(100 台)** | **3D 打印**（100 台还没到注塑平衡点），~¥10–25/个 | 3D 打印 $5–50/件 |
| **10 认证** | 卖给朋友/内部用可暂不认证；正式上架：用 ESP32 预认证模块→只走 SDoC（~$3–5k）；中国卖需 SRRC | 同逻辑，FCC SDoC ~$3–5k |
| **11 量产 100 台** | JLCPCB 批量板 ~¥2–4/片 + JLCSMT 贴片 + 立创买料；EMS/嘉立创一条龙 | 美国 PCBA，单板 ~$35（150 件料）量级，贵约 1 倍 |
| **12 包装物流** | 简易彩盒 + 说明书；国内直发 / 跨境注意 301 关税 | 本土 5–10 天到门，无进口关税 |

**量级对比（100 台，粗略，仅示意）**：
- **中国路径**：BOM ~¥50–60/台 ×100 ≈ ¥5–6k + 打样/贴片/PCB 几百~一千 + 外壳 3D 打印 ¥1–2.5k ≈ **¥8k–1.2万（含一次性费用）**，**3–5 周**走完打样到小批量。**认证另算**（要上架加 ~$3–5k SDoC）。
- **美国路径**：同样 100 台，PCB/PCBA/料价普遍贵 **1.5–2 倍**、NRE 更高，但**本土、无进口关税、合规交付快**。
- **结论**：**打样和 100 台小批量，中国供应链在成本和速度上压倒性占优**；选美国主要是为**本土合规、IP 安全、避关税、交付确定性**。量大且卖美国市场时，把「关税 + 物流 + 合规」算进总落地成本再定。
