# Codex 里查看长输出的稳妥办法

如果当前终端里鼠标滚轮上滑不好用，优先用下面这些办法。

## 1. 先试快捷键

常见可用键：

- `Shift + PageUp`
  - 向上翻一页
- `Shift + PageDown`
  - 向下翻一页
- `Ctrl + Home`
  - 跳到当前缓冲区顶部
- `Ctrl + End`
  - 回到底部

如果你在 VS Code 或类似宿主里，先点一下终端区域，让焦点落在终端里，再试这些键。

## 2. 鼠标滚轮不行时，试滚动条

有些环境里滚轮事件会被外层界面吃掉，但右侧滚动条还能正常拖动。

如果能看到滚动条，优先直接拖。

## 3. 如果还是看不全，不要硬在终端里翻

这是最稳的做法：

- 让我压缩成一屏版
- 让我分段重发
- 让我把内容写进 `G:\blockless-plugin-course(1)\*.md`

对当前这个项目，第三种最稳，因为分析内容本来就偏长。

## 4. 推荐你以后这样用我

如果输出比较长，直接对我说下面任意一种：

- `压缩成一屏版`
- `分 3 段发`
- `只发结论`
- `只发 checklist`
- `写进 G:\blockless-plugin-course(1)\*.md`

这样比在终端里反复上滑更稳定。

## 5. 对你当前项目最推荐的方法

建议固定这样处理长内容：

1. 终端里只看短结论
2. 详细版都写进 `G:\blockless-plugin-course(1)\*.md`
3. 你本地直接打开 markdown 文件看完整内容

这样最适合现在这种：

- skill 改造分析长
- 工作流设计长
- 协议分支多
- 需要反复对照文档

## 6. 一句话结论

如果 Codex 面板里不好上滑，最稳的办法不是继续折腾滚轮，而是：

**让我把长内容写进 `G:\blockless-plugin-course(1)\*.md`，终端只保留短版结论。**
